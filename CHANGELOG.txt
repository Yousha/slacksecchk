slacksecchk 1.1.0.0 - 2026-11-28
* Add --format=json for machine-readable audit summaries and automation-friendly exit codes.
* Add summary counters for passed, failed, and unverified output markers, with JSON escaping and fixture-based tests.
* Add smoke coverage for JSON output shape and exit status.
slacksecchk 1.1.0.0 - 2026-11-28
* Add help and version command-line options and reject unknown options with exit code 2.
* Add automatic terminal color detection with NO_COLOR and TERM=dumb support.
* Add --color=auto|always|never and --no-color options for predictable redirected output.
* Add smoke tests for CLI options and ANSI color behavior.
slacksecchk 1.1.0.0 - 2026-11-27
* Expand effective OpenSSH hardening checks for root login, password authentication, empty passwords, public-key authentication, X11 forwarding, and authentication attempts.
* Add kernel hardening checks for unprivileged BPF, perf events, and BPF JIT hardening when supported by the running kernel.
* Add exact, case-insensitive configuration key/value parsing with duplicate-key ambiguity detection and fixture tests.
* Add shell-free process execution with a fixed executable search path and bounded stdout capture.
* Replace shell pipelines and interpolated commands in audit checks with direct argv execution or native file parsing.
* Remove temporary-file listener discovery and treat command failures or truncated output as unverified.
* Add real-process tests for exit status, missing executables, PATH hijacking resistance, literal shell metacharacters, and output truncation.
-------------------------
* Replace expanded-check stubs with full implementations for all 9 Slackware audit categories.
* Major expansion of Slackware-specific security audits.
* Package surface: slackpkg presence/config, package DB age, packages dir permissions.
* rc.d model: enumerate enabled scripts, high-risk services, script permissions, rc.local/rc.M review.
* Bootloader: LILO password+restricted, enhanced GRUB password detection, config file permissions.
* Kernel: additional hardening sysctls (kptr_restrict, dmesg_restrict, ptrace_scope, rp_filter, syncookies, protected_hardlinks/symlinks, ASLR) and unwanted module checks.
* Authentication: securetty, login.defs aging, PAM password quality, extra UID 0, empty passwords, shells hygiene, sudoers.
* Filesystem: fstab secure options for tmp mounts, /tmp separation, hidepid, world-writable dirs.
* Network: listening sockets on 0.0.0.0, tcp_wrappers, inetd/xinetd.
* Logging: syslog remote reception review, /var/log permissions.
* Misc: X11 -nolisten tcp, compiler presence, issue file leakage, legacy .rhosts/.netrc/hosts.equiv.
